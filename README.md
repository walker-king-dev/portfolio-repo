# Walker King | Portfolio

My professional portfolio: a consolidated site showcasing the four projects I built this semester in WRIT 40363.

**Live site:** https://walker-king-dev.github.io/portfolio-repo/

## Projects

Each project is archived as a snapshot in the `projects/` folder.

## Repository Structure

```
portfolio-repo/
├── index.html          # main portfolio page (the living portfolio)
├── css/                # styles for the main page
├── images/             # images for the main page
├── projects/
│   ├── project1-original/    # Project 1 snapshot: Personal Portfolio
│   ├── project2-tracker/     # Project 2 snapshot: Local Favorites Tracker
│   ├── project3-dashboard/   # Project 3 snapshot: Weather Dashboard
│   └── project-zed/          # Project Zed: PossessionPoint
└── README.md
```

The root `index.html` is the current, enhanced portfolio. The folders inside `projects/` are frozen snapshots of each course project.

## Built With

HTML, CSS

## Design and Accessibility

- Responsive layout for mobile, tablet, and desktop
- Semantic HTML, a skip-to-content link, visible keyboard focus, and alt text on images
- Text and background colors chosen for readable contrast
