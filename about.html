About Me

I am a senior economics major at TCU who is building a career in analytics. This semester I designed, built, and deployed four web projects, going from a static HTML and CSS page to an interactive data dashboard and an AI-assisted web app.

The biggest things I learned were how to structure a page so it works for every visitor, including keyboard users, how to use JavaScript to make data interactive, and how to use Git and GitHub Pages to publish my work. I also learned how to work with AI as a development partner while still checking and understanding every line of code.
